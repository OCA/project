This module restricts the partner selection on projects to companies only.

Individual contacts cannot be selected as project customers.

This module is used by ``sale_partner_sale_contact_on_project`` (available in the
sale-workflow repository) to enforce proper commercial relationships while
allowing contact person tracking.

.. contents::
   :local:

Usage
=====

After installing this module, when selecting a customer on a project,
only partners with the "Is a Company" flag will be available in the dropdown.
