This module requires the following Python libraries:

- `python-gitlab`
- `PyGithub`

Install them with:

    pip install python-gitlab PyGithub

Latest stable releases the module has been tested against:
`python-gitlab` 8.5.0 and `PyGithub` 2.9.1 (older releases down to
`python-gitlab` 7.0.0 / `PyGithub` 2.8.1 are known to work).
