Allows each project to have its own independent order for its task
stages, instead of sharing a single global order across all projects.

When enabled for the company (in Settings), reordering stages from a
project's own Kanban view or from its own Task Stages tab only affects
that project. Reordering from the shared Task Stages list in
Configuration still updates the order for every project that uses that
stage.

This module is useful when you share stages among your projects, but
still want each project to be able to arrange them in its own way.

If you create a new stage with the same name as an existing one (and no
specific user assigned to it), it is automatically merged into the
existing stage instead of creating a duplicate.

Configuration
=============

1. Go to *Settings > General Settings*.
2. Under **Project**, activate **Per-Project Task Stage Order**.
3. Save.

Usage
=====

1. Open a project and go to its **Task Stages** tab.
2. Drag the stages, or add/remove lines, to set the order and membership
   of stages for that project only.
3. The same order is used in that project's Kanban view.
4. To change the order and membership shared by every project instead,
   go to *Project > Configuration > Task Stages*.
