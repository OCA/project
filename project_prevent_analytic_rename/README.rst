This module extends the functionality of Project to support having
separate names for Projects and Analytic Accounts and to allow you to
manage them independently.

Use Cases / Context
===================

This module was developed because sometimes, we don't want to sync
project name with analytic account name.

It will be useful for you if your Financial and Project departments
wants to have separate names for projects and Analytic Accounts.

Usage
=====

To use this module, you need to:

1. Enable Analytic Accounting
2. Create a Project with an Analytic Account and ensure is the only
   project that uses it
3. Change Project name and see how Analytic Account preserves it's
   original name
