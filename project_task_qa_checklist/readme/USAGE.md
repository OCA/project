When a task enters a stage marked as a QA stage, its QA checklist is generated
under the **Internal QA** tab of the task form.

For each line the tester sets the state (Pending, Passed, Failed, Not
Applicable), adds notes, and attaches evidence either as a file or as an
external link. The reviewer and review date are filled automatically when the
state leaves *Pending*.

A progress badge (e.g. `5/8 (63%)`) is shown on the task kanban card, and a
banner on the task form warns when the checklist is incomplete or has failed
criteria.
