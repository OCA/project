This module adds a configurable acceptance-criteria checklist to project
tasks. When a task enters a stage flagged as a QA stage, a checklist of the
criteria that apply to that task is generated so a tester can review, document
and back each criterion with evidence before the task moves on.

Criteria are fully configurable per installation: some apply to every task,
others are triggered by the task's tags. Evidence can be a light attachment
(screenshots) or an external link (recommended for video, to avoid bloating
the database).
