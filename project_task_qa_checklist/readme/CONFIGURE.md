To configure the module:

1. Go to **Project > Configuration > QA Checklist Criteria** and create the
   acceptance criteria. Mark a criterion as *Always Applicable* to generate it
   for every task, or link it to one or more *Tags* to generate it only when a
   task carries any of those tags.
2. Go to **Project > Configuration > Task Stages** (or edit a stage inline)
   and tick **QA Stage** on the stage(s) that represent internal testing in
   your kanban. The module is agnostic of stage names: any stage flagged here
   triggers checklist generation.
