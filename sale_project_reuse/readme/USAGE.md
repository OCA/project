1.  Go to *Sales \> Orders \> Quotations* and create a quotation for a customer
    that has no *Reuse Project* configured yet.
2.  Add a line with a product flagged *Reuse Project*.
3.  Confirm the quotation. The project generated by Odoo is stored as the
    *Reuse Project* of the customer company.
4.  Create a second quotation for the same customer, or for one of its contacts,
    and add a line with a product flagged *Reuse Project*. The *Project* of the
    quotation is filled with the project remembered in step 3.
5.  Confirm the quotation. Its tasks are created in that project, no new
    project is generated.

A project already set on the quotation is never replaced, and is reused the
same way.
