Standard Odoo creates a brand new project for every sales order selling
a service that tracks a project, and there is no place to record which
project belongs to a customer.

This module adds that notion:

-  a *Reuse Project* field on the customer, holding the project to
   reuse,
-  a *Reuse Project* flag on the product,
-  when a flagged product is added to a sales order, the customer's
   project is proposed as the project of that order,
-  confirming that order creates the tasks in the project of the order
   instead of generating a new one,
-  when the customer has no project yet, the project of the first
   confirmed sales order is stored on the customer, so the following
   orders reuse it.

Configuration
=============

1. Go to *Sales > Products > Products* and open a service product whose
   *Create on Order* is *Project & Task*.
2. Tick *Reuse Project*, next to *Project Template*.

Optionally, to reuse a project that already exists:

1. Go to *Sales > Orders > Customers* and open the customer company.
2. In the *Sales & Purchase* tab, set *Reuse Project*.

The field is only shown on the customer company, since the project is
shared by all its contacts.

Usage
=====

1. Go to *Sales > Orders > Quotations* and create a quotation for a
   customer that has no *Reuse Project* configured yet.
2. Add a line with a product flagged *Reuse Project*.
3. Confirm the quotation. The project generated by Odoo is stored as the
   *Reuse Project* of the customer company.
4. Create a second quotation for the same customer, or for one of its
   contacts, and add a line with a product flagged *Reuse Project*. The
   *Project* of the quotation is filled with the project remembered in
   step 3.
5. Confirm the quotation. Its tasks are created in that project, no new
   project is generated.

A project already set on the quotation is never replaced, and is reused
the same way.
