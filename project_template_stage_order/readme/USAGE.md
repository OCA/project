1.  Mark a project as **Is Template?** on its form.
2.  Click **Create Copy**. Enter a name for the new project.
3.  Check **Keep linked to the template** to create a linked copy, or leave
    it unchecked to create an independent copy.
4.  The template's own **Is Template?** checkbox is unchecked automatically
    once the copy is created.
5.  On a linked copy, task stages cannot be reordered, added or removed —
    neither from its Kanban view nor from its **Task Stages** tab. Doing so
    raises an error pointing back to the template.
6.  Changing the task stages on the template (order, additions or removals)
    is applied to every linked copy automatically. Copies that were created
    as independent are not affected.
7.  A project's **Settings** tab shows a **Template** section: which
    template it was copied from, if any, and which copies are currently
    linked to it, if any.
8.  A template cannot be deleted while it still has linked copies — delete
    those first.
