Links a project created from **project_template** to the template it
came from, and keeps its task stages following the template's own
**project_task_stage_order** order.

When a template project is copied, the person copying it can choose to
keep the new project linked to the template. A linked copy's task stages
(order, additions and removals) can only be changed from the template:
any change made on the template is applied to every linked copy
automatically, and linked copies cannot change their own stages. An
independent copy behaves like any other project and keeps no link to the
template.

Tasks are never copied, whether the copy is linked or independent — only
the stage structure is.

Configuration
=============

1. Go to *Settings > General Settings*.
2. Under **Project**, activate **Per-Project Task Stage Order**.
3. Save.

This module has no configuration of its own: it follows the same company
setting as **project_task_stage_order**. While that setting is off,
projects created from a template behave exactly as in plain
**project_template**.

Usage
=====

1. Mark a project as **Is Template?** on its form.
2. Click **Create Copy**. Enter a name for the new project.
3. Check **Keep linked to the template** to create a linked copy, or
   leave it unchecked to create an independent copy.
4. The template's own **Is Template?** checkbox is unchecked
   automatically once the copy is created.
5. On a linked copy, task stages cannot be reordered, added or removed —
   neither from its Kanban view nor from its **Task Stages** tab. Doing
   so raises an error pointing back to the template.
6. Changing the task stages on the template (order, additions or
   removals) is applied to every linked copy automatically. Copies that
   were created as independent are not affected.
7. A project's **Settings** tab shows a **Template** section: which
   template it was copied from, if any, and which copies are currently
   linked to it, if any.
8. A template cannot be deleted while it still has linked copies —
   delete those first.
