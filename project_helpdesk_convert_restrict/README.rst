This module adds a per-company switch **Restrict task-to-ticket
conversion to portal projects** under Settings > Project.

When enabled for a company, converting a task into a helpdesk ticket
(``Convert to Ticket`` action) is only allowed when the task's project
privacy is set to *Invited portal users …*
(``privacy_visibility = 'portal'``). Any other task raises an error
instead of opening the conversion wizard.

This prevents leaking a non-portal task's data through a helpdesk
ticket's public share link.

The switch is off by default (standard Odoo behaviour), scoped per
company (multi-company friendly), and independent of any portal-blocking
module.

Use Cases / Context
===================

The ``project_helpdesk`` bridge lets managers convert a project task
into a helpdesk ticket. A helpdesk ticket can then be shared publicly
through its own portal share link, which is a way to expose data of a
task whose project was never meant to be visible to portal users.

Configuration
=============

Go to Settings > Project and enable **Restrict task-to-ticket conversion
to portal projects** for the current company.

The setting is stored on the company, so in a multi-company database
each company can enable it independently.

Usage
=====

With the setting enabled:

- Open a task whose project privacy is *Invited portal users …* and use
  Action > Convert to Ticket: the conversion wizard opens as usual.
- Do the same on a task of an *All Employees* / *Private* project: an
  error is raised and no ticket is created.
- Converting several tasks at once is blocked as soon as one of them
  belongs to a non-portal project.
