This module extends the project task functionality to allow detailed
resource planning and allocation.

Managing team capacity can be challenging when tasks span long periods.
This module solves that by introducing **Task Allocations**, enabling
managers to assign employees to specific tasks with defined start and
end dates, total hours, and configurable time buckets.

**Key Features:**

- Allocate multiple employees to a single task with specific timeframes
  and planned hours.
- Define planning cycles (Days, Weeks, or Months) to automatically
  generate time buckets.
- Distribute and fine-tune planned hours across individual time buckets
  for precise scheduling.
- Get a clear view of employee workload, total planned hours, and
  remaining availability.

Usage
=====

To use this module, follow these steps:

1. Go to **Project** and open a **Task** that has a defined Start and
   End Date.
2. Navigate to the **Allocations** tab.
3. Click *Add a line* to create a new **Employee Allocation**:

   - Select the **Employee**.
   - Set the **Start Date** and **End Date** (must be within the task's
     timeframe).
   - Specify the total **Allocated Hours** for this resource.

4. Check the control field at the task level to ensure the difference
   between **Estimated Hours** and total **Allocated Hours** is correct.
5. Save the allocation. Once saved, you can generate the planning
   timeline based on your preferred cycle configuration (Days, Weeks, or
   Months) between the allocation's start and end dates.
6. Input and adjust the specific planned hours for each generated time
   bucket to fine-tune the employee's capacity and track availability.
