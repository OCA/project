This module extends the project task functionality to allow detailed resource planning and allocation. 

Managing team capacity can be challenging when tasks span long periods. This module solves that by introducing **Task Allocations**, enabling managers to assign employees to specific tasks with defined start and end dates, total hours, and configurable time buckets.

**Key Features:**
* Allocate multiple employees to a single task with specific timeframes and planned hours.
* Define planning cycles (Days, Weeks, or Months) to automatically generate time buckets.
* Distribute and fine-tune planned hours across individual time buckets for precise scheduling.
* Get a clear view of employee workload, total planned hours, and remaining availability.
