To use this module, follow these steps:

1. Go to **Project** and open a **Task** that has a defined Start and End Date.
2. Navigate to the **Allocations** tab.
3. Click *Add a line* to create a new **Employee Allocation**:
   * Select the **Employee**.
   * Set the **Start Date** and **End Date** (must be within the task's timeframe).
   * Specify the total **Allocated Hours** for this resource.
4. Check the control field at the task level to ensure the difference between **Estimated Hours** and total **Allocated Hours** is correct.
5. Save the allocation. Once saved, you can generate the planning timeline based on your preferred cycle configuration (Days, Weeks, or Months) between the allocation's start and end dates.
6. Input and adjust the specific planned hours for each generated time bucket to fine-tune the employee's capacity and track availability.
