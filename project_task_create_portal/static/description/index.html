Project Portal Task Creation

Allow portal users to create and edit their own tasks from the portal only in a project's pre-configured task stage.

Features

  • New field on project: Portal Task Creation Stage
  • Portal users can create tasks in the pre-defined stages for allowed projects
  • Extended portal UI with "Create Task" button for allowed projects
  • Simplified task creation form (Name, Description, Deadline)
  • Portal users can edit only their own tasks

Configuration

Go to Project App, open a project and click Settings, then set the Portal Task Creation Stage field.

Usage

Portal users can create tasks in allowed projects and edit only their own tasks. Tasks outside the configured stage cannot be created or modified by portal users.
