1. Go to *Project* and open a project: the top menu is shown.
2. Open the dropdown at the end of the top menu and turn on a button, for
   example *Sales Orders*.
3. Open another project, for example from the *Projects* smart button of a
   sales order: the top menu is shown with the same buttons.
4. Hide the top menu with the sliders button next to the view switcher and
   open another project: the top menu stays hidden.
