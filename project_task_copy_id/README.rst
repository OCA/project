This module extends the functionality of Project Tasks to support copy a
custom reference and to allow you to get this reference in your
clipboard fast.

Use Cases / Context
===================

This module was developed because when you want to link a task without
an explicit full link, you need to get the ID of the task and use some
prefix.

It will be useful for you if you need to reference your tasks in a
codified way.

If you use Gitlab, you can configure patterns to open tasks if detects
any.

Configuration
=============

To configure this module, you need to:

1. Go to Settings > Technical > Parameters > System Parameters
2. Create or Update ``project_task_copy_id.prefix`` parameter with a
   prefix your company ususally uses.

If no parameter is found, ``TASK-`` will be used as a prefix.

Is strongly recommended to set a custom one.

The pattern of the task reference will be ``<prefix_pattern><task_id>``

Usage
=====

To use this module, you need to:

1. Go to Configuration > System Paramters and set a prefix like
   'MYTASK-'
2. Go to Project > Tasks and open a task
3. Check a new button on the right of the state selector widget
4. Click on it to get your unique task reference in your clipboard (Eg.:
   MYTASK-1234)
