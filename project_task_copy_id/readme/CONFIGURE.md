To configure this module, you need to:

1. Go to Settings > Technical > Parameters > System Parameters
1. Create or Update `project_task_copy_id.prefix` parameter with a prefix your company ususally uses.

If no parameter is found, `TASK-` will be used as a prefix.

Is strongly recommended to set a custom one.

The pattern of the task reference will be `<prefix_pattern><task_id>`
